# 《音乐电台》Celestial Radio (v6.14.0)

> 为 SillyTavern（酒馆）量身定制的沉浸式 BGM 播放器。内置独立 Sidecar AI DJ 选歌决策引擎、网易云歌单一键全量导入、全库即时模糊搜索、多选批量管理、等离子音频律动波形条与全自由歌单管理。

---

## 🌟 核心能力概览 (Key Features)

### 1. 🤖 独立 Sidecar AI DJ 选歌引擎 (解耦免打扰)
- **主正文 AI 彻底解放**：无需在剧情文本中夹带选歌指令，由专职轻量级 AI DJ 模型异步研判氛围选曲；
- **右上角 `⚙` 设置面板**：支持配置任意 OpenAI 兼容的 Base URL 与 API Key（如 DeepSeek-V3、GPT-4o-mini、Claude-Haiku、本地 Ollama 等）；
- **上下文深度自定义**：默认 **`0 层`（仅取 AI 当前最新回复）**，秒级极速响应且极致节省 Token，支持 1~5 轮历史对话切换；
- **DJ 角色预设与歌单提示词**：支持自由配置与切换 DJ 角色设定（内置“经典优先”与“新鲜感”预设），支持针对特定频段开启并定制提示词文本；
- **一键 `✨ AI选歌`**：面板右上角常驻，随时点击即可让 AI 结合当前剧情场景智能推荐与切歌。

### 2. ☁️ 网易云歌单一键批量导入 (NetEase Playlist Import)
- **云朵导入入口**：各频段标题栏右侧直观配备暗金云朵图标 `☁`；
- **智能识别全链接与纯 ID**：支持直接粘贴网易云分享链接（如 `https://music.163.com/playlist?id=...`）或纯数字歌单 ID；
- **突破 10 首限制**：内置双阶全量解析引擎（优先高精接口，官方 API 双阶兜底），完整提取歌单内全部曲目；
- **智能同名去重**：逐首比对目标频段内现有曲目，同名同歌手自动跳过，新歌曲批量追加合并入库。

### 3. 🔍 全库即时模糊搜索系统 (Instant Global Search)
- **键入即查**：在底栏搜索框键入歌名、歌手或频段名称，跨全库所有频段即时过滤；
- **自动展开与数量指示**：包含匹配歌曲的频段自动展开，并展示匹配数量（如 `匹配 3/12`）；
- **全网连线与直链秒播**：支持回车直接搜索全网，支持粘贴 HTTP/HTTPS 直链秒开播放，未在库曲目提供一键 `[🌐 全网检索并试听]`。

### 4. ☑️ 歌曲批量多选管理系统 (Batch Management)
- **顶部一键多选**：频段展开区顶部点击多选图标 `☑` 开启批量管理；
- **暗金控制栏**：全选/反选、统计已选数量、★ 批量收藏至我的收藏、⇄ 批量跨频段迁移、🗑️ 批量二次确认删除；
- **微光整行点选**：曲目行前置复选框，选中行享有 `.batch-selected` 暗金微光高亮。

### 5. 🎛️ 赛博等离子音频律动波形音量条 (Equalizer Visualizer)
- **24 根独立暗金等离子微柱**：替代传统单调滑轨，播放时柱体随音乐节拍高频上下起伏跳动；
- **音量与振幅双重联动**：音量越大点亮柱数越多、跳动振幅越激烈，静音/暂停时平稳归位；
- **手势滑动与一键静音**：支持在波形图上任意滑动/点击无级调节音量，点击喇叭图标实现静音与记忆恢复。

### 6. 🕒 最近播放历史专属频段与容量配置
- **专属系统频段**：“★ 我的收藏”正下方固化“🕒 最近播放”频段，发声播放时自动去重记录足迹；
- **自由容量调节**：设置面板提供 5 / 10 / 20 / 30 / 50 首历史容量自由配置（默认 10 首）；
- 支持在历史记录中直接收藏、编辑、跨频段迁移或单曲删除。

### 7. 🎯 歌曲匹配与检索算法概述
- **四级递进解析机制**：
  1. **直链秒播**：检测到 HTTP/HTTPS 音频直链直接建立播放管道；
  2. **本地高精直链库**：泽野弘之神曲（`YouSeeBIGGIRL/T:T`, `ət'aek 0N tάɪtn`, `立body!机st` 等）、Evan Call、星际穿越等经典曲目优先命中，0ms 秒开；
  3. **连字符双态解析引擎**：智能自适应 `歌名 - 歌手` 与标题自带横杠的复杂歌名（如 `Monoco's Station - Grandis Refuge`），杜绝误切断；
  4. **多源全网模糊检索与打分模型**：综合歌名完整度、歌手吻合度、OST 原声意图及名家名单进行多维加权打分，自动剔除劣质翻唱与低质伴奏。
- **1~9 分钟双层硬核时长过滤网**：前置码率体积预估 + 硬件元数据加载时自动熔断，**100% 屏蔽小于 1 分钟短试听与大于 9 分钟有声书/长播客**。

### 8. 📂 全自由歌单与资产管理
- **导入双模式**：
  - **覆盖导入**：全量重装替换当前列表；
  - **增量合并导入**：智能合并同名频段，自动跳过重复歌曲，绝不删除本地现有曲库；
- **歌曲收藏与跨频段移动**：支持一键收藏至【★ 我的收藏】，支持点击 `⇄` 模态选择目标频段或直接 HTML5 拖拽；
- **原声 MP3 导出**：一键捕获正在播放的 320kbps 音频流并下载为 `歌名 - 歌手.mp3`；
- **频道与歌曲全字段编辑**：所有频段与单曲均可随时重命名、修改作者与真实直链 URL。

### 9. 🎨 极致紧凑的暗金深空 UI
- **Jura & Noto Serif SC** 赛博字体排版，`#C4A77D` 暗金矢量 SVG 图标；
- **新建歌单置顶**，单曲刻录与图标管理栏同列置顶，底部搜索与节点管理紧凑单行合并，为歌单列表争取最大化纵向显示空间；
- **智能边缘贴边收纳把手**，支持左右吸附与垂直拖拽。

## 🚀 安装与使用指南 (Getting Started)

1. **导入脚本**：
   - 打开 SillyTavern（酒馆），在【酒馆助手】扩展的脚本管理器中点击导入，选择 `酒馆助手脚本-电台直链版.json`；
   - 或直接将脚本内容复制到 Tampermonkey（油猴）中运行。
2. **导入网易云歌单**：
   - 点击任意频段标题右侧的云朵图标 `☁`；
   - 粘贴网易云歌单分享链接或纯 ID，点击确定即可一键批量去重导入。
3. **配置 AI DJ 接口（可选）**：
   - 点击电台面板右上角 **`⚙`** 齿轮图标；
   - 填入您的 API 地址（如 `https://api.deepseek.com/v1`）与 API Key，选择模型（如 `deepseek-chat`）；
   - 勾选【正文生成后自动选歌】即可实现全自动 BGM 切换！
4. **日常播放与搜索**：
   - 点击右上角 `✨ AI选歌`、点击歌单曲目、或在底栏输入关键词实时过滤全库曲目。
