# 《音乐电台》Celestial Radio (v6.0)

> 为 SillyTavern（酒馆）量身定制的沉浸式 BGM 播放器。内置独立 Sidecar AI DJ 选歌决策引擎、本地直链秒播、智能双态检索与全自由歌单管理。

---

## 🌟 核心能力概览 (Key Features)

### 1. 🤖 独立 Sidecar AI DJ 选歌引擎 (解耦免打扰)
- **主正文 AI 彻底解放**：无需在剧情文本中夹带选歌指令，由专职轻量级 AI DJ 模型异步研判氛围选曲；
- **右上角 `⚙` 设置面板**：支持配置任意 OpenAI 兼容的 Base URL 与 API Key（如 DeepSeek-V3、GPT-4o-mini、Claude-Haiku、本地 Ollama 等）；
- **上下文深度自定义**：默认 **`0 层`（仅取 AI 当前最新回复）**，秒级极速响应且极致节省 Token，支持 1~5 轮历史对话切换；
- **提示词 Debug 模式**：F12 控制台优雅展示完整的系统提示词、剧情 Payload 与原始模型决策返回；
- **一键 `✨ AI选歌`**：随时点击即可让 AI 结合当前战况/情景重新推荐配乐。

### 2. 🛡️ 极致容错与 1~9 分钟硬核时长过滤
- **连字符双态解析引擎**：完美解决 `Monoco's Station - Grandis Refuge` 等歌名自带横杠被错误切分的问题；
- **双层时长熔断**：前置按码率计算过滤 + 硬件元数据加载时自动熔断，**100% 屏蔽小于 1 分钟短试听与大于 9 分钟有声书/长播客**；
- **本地神曲直链库**：泽野弘之神曲（`YouSeeBIGGIRL/T:T`, `ət'aek 0N tάɪtn`, `立body!机st` 等）、Evan Call、星际穿越、星际拓荒等经典曲目 0 毫秒秒开。

### 3. 📂 全自由歌单与资产管理
- **导入双模式**：
  - **覆盖导入**：全量重装替换当前列表；
  - **增量合并导入**：智能合并同名频段，自动跳过重复歌曲，绝不删除本地现有曲库；
- **歌曲收藏与跨频段移动**：支持一键收藏至【★ 我的收藏】，支持点击 `⇄` 模态选择目标频段或直接 HTML5 拖拽；
- **原声 MP3 导出**：一键捕获正在播放的 320kbps 音频流并下载为 `歌名 - 歌手.mp3`；
- **频道完全可编辑**：所有预置与自定义频段均可自由重命名、删除或排序，并提供 `[重置]` 随时恢复出厂。

### 4. 🎨 暗金典雅矢量 UI
- **Jura & Noto Serif SC** 赛博字体排版；
- **`#C4A77D` 暗金矢量 SVG 图标**，纯粹优雅；
- **智能边缘贴边收纳把手**，支持左右吸附与垂直拖拽。

## 🚀 安装与使用指南 (Getting Started)

1. **导入脚本**：
   - 打开 SillyTavern（酒馆），在【酒馆助手】扩展的脚本管理器中点击导入，选择 `酒馆助手脚本-电台直链版.json`；
   - 或直接将脚本内容复制到 Tampermonkey（油猴）中运行。
2. **配置 AI DJ 接口（可选）**：
   - 点击电台面板右上角 **`⚙`** 齿轮图标；
   - 填入您的 API 地址（如 `https://api.deepseek.com/v1`）与 API Key，选择模型（如 `deepseek-chat`）；
   - 勾选【正文生成后自动选歌】即可实现全自动 BGM 切换！
3. **日常播放**：
   - 随时点击 `✨ AI选歌`、点击歌单曲目、或在顶部搜索框输入歌名/直链播放。
